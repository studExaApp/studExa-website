# StudExa Website

Static, responsive multipage website.

Pages:
- index.html — Home
- features.html — Features overview
- about.html — About StudExa
- feedback.html — Survey introduction
- feature-survey.html — Full feature survey
- contact.html — Contact form (opens the visitor's email app)

Upload the contents of this folder to the root of your Cloudflare Pages project.
No developer credits, internal implementation notes, API keys beyond the existing Firebase public web config inside the survey, or setup details are displayed in the public-facing pages.

Note: the contact form uses a mailto link because no contact email or form backend was supplied. Configure a real contact endpoint before using it for production enquiries.
